# StridePlan 马术障碍路线设计器

基于 React、TypeScript、Vite、Mantine、Zustand 和 React Router 构建。场地和障碍使用
Canvas 按真实米制尺寸绘制，所有数据保存在浏览器本地。

## 功能

- 标准 60 × 90 米场地、栅格吸附和缩放
- 障碍类型 / 颜色库、编号、旋转、拖动和顺序调整
- 按马匹步幅、接近段、落地段计算推荐步数
- 距离不合理、转角过急和路线交叉实时检查
- 按难度生成三套备选路线并一键应用
- 撤销重做、本地路线库、分享链接
- 可打印路线图和裁判用 CSV 表
- **可续作的协作链接**：两位教练共用同一文档，断网也能接着挪障碍、调跳次顺序，回网点“取回并合并”按 diff3 三方合并（base / 本机 / 对方）
  - 无冲突的调整自动并入；同一障碍同一字段两边都改、删除与调整撞车、跳次顺序在同一区域都被重排时，先保留两版并标出冲突，逐条裁决后才能保存
  - 合并前版本持久化为检查点：可“从合并前重试”（已并入内容与已做裁决不丢）或“回到合并前”
  - 保存走 CAS（compare-and-swap）：两人同时保存时只有期望版本匹配的一份成立，败者取回合并后重存
  - 纯前端以同源 localStorage 模拟共享盘；跨设备通过互发的链接合并
- **步数表/稳定度失效管控**：场地尺寸或马匹步幅（含接近段、落地段）一变，步数表与稳定度立即标记失效并要求重算；旧参数的裁判表（CSV 与打印路线图）重算前禁止导出（界面与导出函数双层拦截）
